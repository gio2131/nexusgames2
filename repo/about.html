About

A static site. Three pages and a player.

Every game here is a self-contained HTML5 build that loads straight into the page. There is no backend, no login and nothing stored on a server — the whole site is plain HTML, CSS and JavaScript.

Adding a game

  • Drop the build into games/your-slug/ with an index.html at its root.
  • Add an entry to assets/js/games-data.js with a matching id and url.
  • Reload. It shows up in the grid and the category chips update on their own.

Thumbnails

Optional. Add thumb: "assets/img/your-slug.png" to an entry and it gets used; leave it off and a lettered tile is drawn instead, so the grid never has holes in it.

Keyboard

  • / — focus the search box on the games page.
  • Esc — clear the search.
